## 📖 About

In large Discord communities, malicious users often use **Alt Accounts** (Fake/New Accounts) to spread DM advertisements. However, they frequently use **Permanent Links** generated by their **Main Accounts**.

**Forensic Engine** decodes these links to reveal the true identity of the creator, effectively unmasking the person behind the campaign.

### Key Capabilities

| Feature | Description |
|---------|-------------|
| 🔗 Link Tracing | Decode any Discord invite link to find the original creator |
| 👤 User Analysis | Deep permission analysis and mutual server mapping |
| 🛡️ Anti-Alt | Detect fake accounts used for spam/advertisement |
| 📊 Metadata Extraction | Extract server metadata with high precision |

---

## ⚡ Features

- **Instant Link Analysis** - Decode invite links in real-time
- **Creator Identification** - Find who originally created the link
- **Permission Matrix** - Full role and permission analysis
- **Mutual Server Mapping** - Discover shared servers between users
- **Ownership Detection** - Identify server owners instantly
- **Account Timestamps** - Track account creation dates
- **Boost Detection** - Server boost level and count
- **Verification Level** - Server security level

## 🎮 Commands

### `/check <link>`

**High-precision forensic analysis & metadata extraction**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `link` | String | ✅ | Target invite link or code |

**Output Includes:**
- 🛡️ Server Info (Owner ID, Creation Date, Guild ID, Verification Level)
- 👤 Link Creator (Username, ID, Account Creation Date)
- 🔗 Link Integrity (Permanent/Temporary, Expiration Time)
- 🧪 Server Boosts (Count & Level)
- 📊 Population (Total & Online Members)

---

### `/checkuser <id>`

**Forensic Radar 2026: Deep Permission Analysis**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | String | ✅ | Target User ID |

**Output Includes:**
- 📋 Core Identity (Name, Username, ID)
- 🕰 Time Logs (Account Creation Date)
- 👑 Ownership Detection (Servers Owned)
- 📜 Permission Trace (Full Matrix)
- 🌐 Mutual Server Directory

## ⚙️ Configuration

### Option 1: Environment Variables (Recommended)

Create a `.env` file in the project root:

```env
TOKEN=your_bot_token_here
CLIENT_ID=your_client_id_here
USER_TOKEN=your_user_token_here
```

### Option 2: Direct Configuration

Edit the following files:

**index.js**
```javascript
const TOKEN = 'your_bot_token';
const CLIENT_ID = 'your_client_id';
```

**commands/checkuser.js**
```javascript
const USER_TOKEN = 'your_user_token';
```

### Getting Your Tokens

| Token | Where to Find |
|-------|---------------|
| `TOKEN` | [Discord Developer Portal](https://discord.com/developers/applications) → Bot → Token |
| `CLIENT_ID` | [Discord Developer Portal](https://discord.com/developers/applications) → General Information |
| `USER_TOKEN` | Enable Developer Mode in Discord → Right-click your profile → Copy User Token |

### Token Security

```
⚠️ IMPORTANT: Never share your tokens or commit them to GitHub!

✅ DO:
  - Use .env file
  - Add .env to .gitignore
  - Keep tokens secret

❌ DON'T:
  - Hardcode tokens in source files
  - Share tokens publicly
  - Commit tokens to version control
```

## 📌 Requirements

| Requirement | Status | Notes |
|-------------|--------|-------|
| Node.js 18+ | ✅ Required | Latest LTS recommended |
| discord.js v14 | ✅ Required | Core bot functionality |
| discord.js-selfbot-v13 | ✅ Required | For /checkuser command |
| Mutual Server | ⚠️ Required | For /checkuser command |
| Bot Permissions | ✅ Required | Administrator recommended |

### Important Notes

- **Mutual Server Required:** For `/checkuser` to work, the scraper account must share at least one server with the target.
- **Self-Botting:** The `/checkuser` command uses `discord.js-selfbot-v13`. Self-botting is against Discord's Terms of Service.
