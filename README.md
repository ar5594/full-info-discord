## 📖 About

In large Discord communities, malicious users often use **Alt Accounts** to spread DM advertisements. However, they frequently use **Permanent Links** generated by their **Main Accounts**.

**Forensic Engine** decodes these links to reveal the true identity of the creator, effectively unmasking the person behind the campaign.

---

## ⚡ Features

- 🔗 **Link Tracing** - Decode any Discord invite link to find the original creator
- 👤 **User Analysis** - Deep permission analysis and mutual server mapping
- 🛡️ **Anti-Alt Detection** - Detect fake accounts used for spam/advertisement
- 📊 **Metadata Extraction** - Extract server metadata with high precision

---

## 🔄 How It Works

1️⃣ **LINK INPUT** - User submits discord.gg invite link, system validates format

2️⃣ **DEEP TRACE** - Decode invite metadata, extract creator identity, fetch server info

3️⃣ **ANALYSIS** - Generate forensic report, display permissions, map connections

4️⃣ **EXPOSURE** - Reveal main account behind alt, show creation date, provide evidence

## 🎮 Commands

### `/check <link>`

High-precision forensic analysis & metadata extraction

- **Parameter:** `link` (string) - Target invite link or code

**What you get:**
- 🛡️ Server Info (Owner ID, Creation Date, Guild ID, Verification Level)
- 👤 Link Creator (Username, ID, Account Creation Date)
- 🔗 Link Integrity (Permanent/Temporary, Expiration Time)
- 🧪 Server Boosts (Count & Level)
- 📊 Population (Total & Online Members)

---

### `/checkuser <id>`

Forensic Radar 2026: Deep Permission Analysis

- **Parameter:** `id` (string) - Target User ID

**What you get:**
- 📋 Core Identity (Name, Username, ID)
- 🕰 Time Logs (Account Creation Date)
- 👑 Ownership Detection (Servers Owned)
- 📜 Permission Trace (Full Matrix)
- 🌐 Mutual Server Directory

## 🚀 Installation

### Prerequisites

- [Node.js](https://nodejs.org/) v18.0 or higher
- A [Discord Developer Portal](https://discord.com/developers/applications) account
- npm or yarn package manager

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/ar5594/full-info-discord.git

# 2. Navigate to directory
cd full-info-discord

# 3. Install dependencies
npm install

# 4. Start the bot
npm start
```

---

## ⚙️ Configuration

### Step 1: Create `.env` file

Create a file named `.env` in the main folder and add:

```env
TOKEN=your_bot_token_here
CLIENT_ID=your_client_id_here
USER_TOKEN=your_user_token_here
```

### Step 2: Get Your Tokens

- **TOKEN** - From [Discord Developer Portal](https://discord.com/developers/applications) → Bot → Token
- **CLIENT_ID** - From [Discord Developer Portal](https://discord.com/developers/applications) → General Information
- **USER_TOKEN** - Enable Developer Mode in Discord → Right-click your profile → Copy User Token

### Step 3: Start the Bot

```bash
npm start
```

## 📌 Requirements

- ✅ Node.js 18+ (Latest stable version)
- ✅ discord.js v14 (Core bot functionality)
- ✅ discord.js-selfbot-v13 (For /checkuser command)
- ⚠️ Mutual Server (Required for /checkuser)
- ✅ Bot Permissions (Administrator recommended)

### Important Notes

- **Mutual Server Required:** For `/checkuser` to work, the scraper account must share at least one server with the target.
- **Self-Botting:** The `/checkuser` command uses `discord.js-selfbot-v13`. Self-botting is against Discord's Terms of Service.

## 🔧 Troubleshooting

- **Bot doesn't respond** - Check if token is correct in `.env`
- **Commands not showing** - Run `npm start` again to re-register commands
- **`/checkuser` fails** - Make sure there is a mutual server with the target
- **Permission denied** - Grant Administrator permission to bot
